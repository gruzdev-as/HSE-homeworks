# Домашние задания — курс Python для магистров «ИИ в маркетинге»

Репозиторий с домашними заданиями курса Python. Задания рассчитаны на два
параллельных трека: «новички» (базовая часть) и «Смешарики» (базовая часть
+ опциональные задачи со звёздочкой).

## Структура

- [hw1-basics/](hw1-basics/) — ДЗ1: основы языка (после 6 семинара).
- hw2-functions/ — ДЗ2: функции и рефакторинг (после 8 семинара).
- hw3-oop/ — ДЗ3: ООП (после 11 семинара).
- hw4-scraping/ — ДЗ4: парсинг (опционально, срок открыт).

Каждая папка с домашкой содержит свой README с условием задания. Проверка
запускается автоматически через GitHub Actions при пуше — скрытые тесты
подтягиваются из отдельного приватного репозитория и студенту не видны.
